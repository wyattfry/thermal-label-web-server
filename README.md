# Thermal Label Printer Web Interface

This Python / Flask program hosts a web page for users to send image files (pdf, jpg, png, etc) to print on a USB attached thermal label printer. It was developed because I'm too dumb to figure out how to share the thermal printer over the network.

## Preequisites

* Windows
* Python
* Flask
* Sumatra PDF
* PyMuPDF
* Microsoft Visual C++ Redistributable
